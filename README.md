# GameVault Android

Android WebView wrapper for the live GameVault website: https://congdonggialap.site/

- Native app icon
- Downloads intercepted by Android WebView and saved to Download/GameVault/
- Custom in-app progress dialog with percentage, bytes, speed, elapsed time and ETA
- GitHub Actions builds a debug APK and uploads it as an artifact

Pushes to main trigger the build. The APK is available from the Actions run under Artifacts.
